### About

Co-founder of **[Pulse Wave Tech](https://pulsewavetech.io)** — a small federal subcontracting company in Maryland. Spent 9 years in the U.S. Air Force, then moved into federal contracting, then started building the internal tooling I wished existed. I think in systems and infrastructure: where does it run, how does it connect, what happens when the network blips.

I write across the stack — TypeScript, Python, PowerShell, the occasional bit of Rust — and run a Proxmox homelab that hosts most of what I build.

### Currently building

- **[claude-memory-template](https://github.com/zriser/claude-memory-template)** — a persistent knowledge vault for Claude Code sessions. Hooks extract insights, scripts compile them into a wiki.
- **pulse-wave-hq** — internal ops dashboard for the business: candidate matching, rate calc, sub onboarding.
- **Sage** — meal-planning app (mobile + API), private until it isn't.
- A homelab that keeps quietly absorbing more responsibilities than it was scoped for.
